# 7 Gates – Chocolate Store

An Arabic (RTL) online chocolate store built with plain HTML, CSS and JavaScript.

**Live demo:** https://hends3368-cpu.github.io/7-gates-chocolate-store/

## Features
- Responsive layout: sticky header, hero banner, product grid, about and contact sections
- 19 products with categories (Hazelnut, Belgian, Honey, Assorted Sweets)
- Category filter and product search
- Quantity selector and shopping cart saved in `localStorage`
- Checkout page: order summary, quantity edit/remove, delivery details form, cash or card on delivery
- Order confirmation sends the full order to the store's WhatsApp

## Files
- `index.html` – home page and products
- `checkout.html`, `checkout.js` – cart and checkout
- `script.js` – cart, filter and search logic
- `styel.css` – styles

## Tech
HTML5 · CSS3 (Grid, Flexbox, media queries) · Vanilla JavaScript · Font Awesome
